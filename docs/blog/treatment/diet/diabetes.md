# 得糖尿病10年，我把血糖控得和正常人一样，这些坑别踩！

![糖尿病患者日常测血糖场景](https://source.unsplash.com/1600x900/?diabetes,glucose)

大家好，我是老周，今年42岁，确诊2型糖尿病正好10年。还记得32岁那年拿到确诊报告的时候，我整个人懵在医院走廊里，兜里揣着刚上幼儿园的女儿的照片，脑子里全是乱七八糟的念头：是不是要打一辈子针？会不会得并发症看不到女儿上大学？那段时间是我人生最低谷的时期，试过各种偏方，踩了无数的坑，花了好几万冤枉钱，才慢慢摸出了适合自己的控糖方法。现在我已经停药2年，糖化血红蛋白一直稳定在5.7-5.9之间，上次复查医生都夸我控得比很多糖尿病前期的人还好。今天把我的经验分享给大家，刚确诊的糖友别慌，糖尿病不是绝症，好好管理好完全可以和正常人一样生活。

## 刚确诊头3年，我踩过的那些要命的坑
我前3年我几乎是在试错的3年，现在回头看很多做法真的是拿健康开玩笑，大家千万别学我。
第一个坑：靠饿肚子控糖，差点晕在公司。当时看糖友群里有人说“糖尿病就是吃越少越好”，我当时180斤，就顿顿吃水煮青菜加一块鸡胸，主食一口都不碰，2个月掉了30斤还沾沾自喜。结果有次开晨会突然眼前一黑栽了下去，同事送医后测血糖只有2.8，严重低血糖，医生说再晚来半小时都可能出人命，后来还查出了慢性胃炎，被医生骂了整整半小时，说高血糖的危害是长期的，低血糖一次就可能要命，别瞎折腾。
第二个坑：迷信“降糖神物，反而把血糖吃更高。当时不敢碰甜的，就买了一堆网红无糖饼干、无糖沙琪玛，想着无糖就可以随便吃，一次啃半袋，结果测餐后血糖直接飙到11.2，我当时都懵了。后来看配料表才发现，第一位就是小麦粉，加了麦芽糖醇和大量油脂，每100克有70多克碳水，比白米饭升糖还快。后来还刷到过号称“喝了就能停降糖药”的降糖神茶，花三千多买了半年的量，偷偷停了二甲双胍，喝了半个月浑身乏力，复查糖化血红蛋白直接到8.2，比之前还高了1个点，吓得我赶紧把剩下的茶全扔了，老老实实吃药。
第三个坑：盲目高强度运动，搞出膝盖积液。当时听说运动能降糖，我每天早上硬扛着180斤的体重跑5公里，不管刮风下雨都坚持，跑了半个月膝盖疼得上下楼都费劲，去查是膝盖积液，医生说我体重基数大，一开始就跑这么多膝盖根本受不了，反而得不偿失，让我先从慢走开始。

## 摸了7年的稳糖实操方法，我和身边十几个糖友都有用
![适合糖友的健康饮食搭配](https://source.unsplash.com/1600x900/?diabetes,healthy,food)

踩了无数坑之后我才明白，控糖根本不需要苦行僧一样的生活，找对方法反而很轻松。
### 饮食：不用饿肚子，3个小技巧稳血糖
我现在一顿饭吃得饱，血糖也不高，全靠这三个方法：第一是主食换1/3粗粮，每顿吃一拳的量，白米混1/3糙米或者藜麦，有时候换成一小块红薯或者玉米，搭配一拳头的瘦肉/鱼虾，两拳头的绿叶菜。第二是调整吃饭顺序，先吃菜，再吃肉，最后吃主食，我亲测这样吃餐后血糖比先吃主食至少低2个点，现在餐后2小时基本都在6.5-7.5之间，从来没超7.8。第三是不用完全忌口，想吃甜的的时候就吃100克左右的草莓或者小番茄，实在想吃蛋糕就切1小块，当天的主食减1/3，吃完测一下血糖没问题就可以，憋久了反而容易情绪性暴食，血糖波动更大。
### 运动：选对方式比时长更重要
我现在每天吃完晚饭先站半小时，不坐沙发也不躺，然后下楼慢走20分钟，每周抽3天打羽毛球或者快走40分钟，不累还能把餐后血糖压得很稳。口袋里永远装2颗水果糖，要是觉得头晕、出冷汗赶紧吃一颗，避免低血糖。之前我也遇到过运动完血糖反而高的情况，后来问医生才知道，剧烈运动的时候身体会分泌升糖激素，所以不用追求高强度，适合自己的才最好。
### 监测：找对规律比焦虑数值有用
我现在不用天天测血糖，每周测3天的空腹和三餐后2小时就行，每次吃新的食物就测一下，记下来自己的耐受量，比如我吃西瓜一次吃100克没问题，吃200克就高，那我以后就控制在100克以内。每3个月去医院查一次糖化血红蛋白，这个是反映3个月的平均血糖，比单次的血糖数值更有参考意义。
#### 真实案例
我楼下的张叔比我晚2年确诊糖尿病，之前糖化一直7.8左右，管不住嘴顿顿吃白米饭还爱喝粥，后来跟着我按这个方法调整，把一半白米饭换成杂粮，改了吃饭顺序，每天吃完饭下楼走20分钟，3个月之后复查糖化直接降到了6.3，药量也减了一半，他说之前经常乏力的情况现在也没了。

## 常见问题（FAQ）
1. **得了糖尿病是不是这辈子都不能吃甜的了？
答：真的不是！我现在夏天也会偶尔吃半根冰棒、一小块奶油蛋糕，只要血糖控制稳定，少量吃是完全可以的，控制好量就行，不用有负罪感，反而完全忌口容易导致情绪性暴食，反而让血糖波动更大。
2. **降糖药有依赖性，一旦吃上就停不了？
答：我之前吃了5年的二甲双胍，后来体重降到了标准范围，饮食运动也能稳定住血糖，医生评估后给我减了药量，现在已经停药2年了，血糖一直很稳定。千万不要自己私自停药，一定要定期复查，听医生的评估，不要自己瞎琢磨停药反而害了自己。
3. **无糖食品是不是可以随便吃？
答：绝对不行！很多无糖食品只是没有添加蔗糖，但是里面有大量的淀粉、麦芽糊精、碳水化合物，升糖速度比白米饭还快，而且很多代糖吃多了会影响肠道菌群，增加代谢负担，买之前一定要看配料表和营养成分表，碳水含量高的再便宜也别买。
4. **为什么我运动之后血糖反而更高了？
答：我之前也遇到过这种情况，要是你做的是高强度的运动，比如快跑、举重，身体会应激分泌升糖激素，导致血糖暂时升高，这种情况不用慌，换成低强度的有氧运动就行，运动前测一下血糖，要是低于5mmol/L，先吃一小块饼干再运动，避免低血糖。
