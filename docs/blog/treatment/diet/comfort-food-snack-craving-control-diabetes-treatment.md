# 治疗期加餐与馋意控制：把冲动进食变成可管理流程

> **[English Version](./comfort-food-snack-craving-control-diabetes-treatment-en)**

很多人并非主餐失控，而是下午和夜间加餐失控。解决关键在流程，而不是意志力。

## 3步流程

1. 先判断：是真饿还是情绪触发？
2. 先替代：水/无糖茶 + 10分钟活动。
3. 仍饿再吃：蛋白+纤维小份加餐。

## 低风险加餐示例

- 无糖酸奶 + 坚果
- 鸡蛋 + 黄瓜
- 豆腐 + 番茄
