# 糖尿病高频问题实用解答

> **[English Version](./diabetes-common-questions-answered-en)** | **[英文版入口](./diabetes-common-questions-answered-en)**

高频问题反复出现并不可怕，说明你在主动建立自己的管理系统。

## 常见问题摘选
### 我需要每天都测血糖吗？
取决于你的治疗阶段与风险水平。重点是“稳定执行”，而不是盲目增加次数。

### 糖尿病就不能吃碳水了吗？
不是。关键在于总量、质量和搭配结构。

### 为什么今天和昨天差很多？
饮食、睡眠、压力、活动、疾病状态、用药时点都会影响波动。
