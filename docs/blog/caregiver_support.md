# 沉默的伙伴：糖尿病亲友支持指南

> **[English Version](./caregiver_support-en)** | **[英文版入口](./caregiver_support-en)**

糖尿病不仅影响患者个人，也影响着整个家庭。作为配偶、父母或朋友，你目睹着血糖的高低起伏（无论字面上还是象征意义上），往往感到无助。你想提供帮助，但又不想变得唠叨。

如何在“支持性伴侣”和“糖尿病警察”之间找到微妙的平衡？

## 1. 询问，而不是假设
最常见的摩擦点是什么？未经请求的饮食建议。“你该吃那个吗？”这句话引发了无数次争吵。
*   **更好的方法：** 询问你的亲人，*“在饮食方面，你希望我如何支持你？”* 他们可能会说，“请不要评论我的盘子，”或者“如果我们家里不放冰淇淋，我会很高兴。”让他们来设定界限。

## 2. 了解低血糖的迹象
低血糖会在几分钟内改变一个人的性格。他们可能会变得易怒、困惑、颤抖或嗜睡。
*   **你的工作：** 了解他们具体的症状。如果他们表现反常，温柔地问一句，*“你最近测过血糖了吗？”* 并且在显眼的地方备好急救葡萄糖（果汁、糖片、凝胶）。

## 3. 参与，而不是发号施令
当生活方式的改变是共同进行时，会变得更容易。与其叫他们去散步，不如说：*“我需要呼吸点新鲜空气，想和我一起去吗？”* 与其叫他们多吃蔬菜，不如直接做一顿美味的、蔬菜丰富的饭菜大家一起分享。

## 4. 理解倦怠感
“糖尿病痛苦（Diabetes Distress）”是真实存在的。这是全年无休管理慢性病所带来的情感负担。有时他们会愤怒，有时他们会悲伤。
*   **支持：** 认可他们的感受。*“必须面对这些真的很糟糕。我很抱歉你现在这么难过。”* 你不需要解决它；你只需要见证它。

## 5. 照顾好你自己
看护者倦怠也是真实存在的。你不能从空杯子里倒出水来。确保你有自己的支持系统或独立于疾病之外的爱好。

作为“3型糖尿病”（对糖尿病支持者的昵称）是一个至关重要的角色。你的耐心和陪伴，让糖尿病这一沉重的负担变得轻了一点点。
