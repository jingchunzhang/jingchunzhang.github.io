# 糖尿病关键术语速通：把看不懂变成看得懂

> **[English Version](./diabetes-terms-you-should-know-en)** | **[英文版入口](./diabetes-terms-you-should-know-en)**

很多人不是不重视健康，而是被术语卡住。先理解词，再理解治疗。

## 优先掌握的5个词
- **HbA1c**：近2–3个月平均血糖趋势。
- **空腹血糖**：隔夜空腹后的基础水平。
- **餐后血糖**：进食后的血糖反应。
- **低血糖**：需要及时处理的低值状态。
- **胰岛素抵抗**：机体对胰岛素反应下降。

## 更高效的用法
1. 把术语和你的检验单逐项对应。
2. 下次就诊前列出3–5个不懂的词。
3. 用手机维护“个人医疗词汇表”。
