# 打了3年胰岛素，我总结了这份人人能懂的实用指南
![胰岛素注射工具与血糖测量仪](/assets/images/generated/gen_1774000114_576.png)

32岁那年我查出2型糖尿病，当时糖化血红蛋白已经到了9.2，医生当场就建议我短期打胰岛素强化治疗。我当时听完脑袋嗡的一声，满脑子都是「打胰岛素是不是一辈子都离不开了？」「扎针会不会特别疼？」，愣是抗拒了半个月才肯开始用。这3年我踩过不少坑，也摸出了很多实用的经验，今天就把大家关心的关于胰岛素的问题都讲清楚，帮需要的朋友少走弯路。

## 一开始我对胰岛素的3个误解，现在想想真可笑
我刚开始接触胰岛素的时候，踩的大部分坑都是因为认知错误，这几个误区也是我接触过的糖友最常问的：
1. **打胰岛素会上瘾，一辈子都停不了**：我刚确诊的时候死活不肯打，就是怕上瘾，拖了半个月血糖忽高忽低，整个人整天昏昏沉沉。后来医生跟我说，胰岛素本身就是身体分泌的一种激素，打胰岛素只是补充身体的不足，根本不存在成瘾的问题。我自己初发的时候打了半年胰岛素，胰岛功能恢复后，还停了1年多靠口服药控糖，后来是因为经常熬夜饮食不规律，口服药压不住才又打胰岛素的，完全没有依赖的情况。
2. **打胰岛素特别疼**：我第一次自己扎针的时候手抖了5分钟，扎完肚皮青了整整一周，以为打胰岛素就是要遭罪。后来才知道疼大多是操作不对导致的：针头重复用变钝、进针角度不对、打在了硬结上，现在我用最新的超细针头，每次快进快出几乎没有痛感，身边还有糖友用胰岛素泵，日常根本感受不到扎针的不适。
3. **打了胰岛素就可以随便吃**：这是我踩过最险的坑，刚打胰岛素的第一个月，我以为有了「护身符」，偷偷喝了全糖奶茶还吃了牛油火锅，结果当天晚上血糖飙到16.8，头晕恶心，半夜被家人送急诊，医生说我这种行为特别容易诱发酮症酸中毒，现在想想都后怕。

## 我整理的胰岛素正确使用实操步骤，照着做少走弯路
这几年我跟着护士学了不少规范操作的技巧，也自己总结了很多注意点，新手照着做基本不会出大问题：

### 打之前的准备工作
首先要核对胰岛素类型和有效期：我刚打第二个月就拿错过，把睡前打的长效胰岛素当成餐前的短效打了，结果空腹血糖低到3.2，坐在沙发上冒冷汗站不起来。大家一定要分清：长效胰岛素通常每天固定时间打1次，管24小时基础血糖；短效/速效胰岛素是餐前打，管这一顿的餐后血糖。另外开封的胰岛素不需要放冷藏，室温（25℃以下）存放就行，开封后1个月就不能用了，没开封的要放在2-8℃的冰箱冷藏层，绝对不能冷冻。我之前夏天把开封的胰岛素放在车里晒了2小时，直接失效了，打了跟没打一样，血糖当天就飙到14。
其次要做好排气：新换的针头一定要先拧1-2个单位，看到针尖有药珠冒出来再打，不然打进去的是空气，实际药量就不准了。
### 注射的正确姿势
偏瘦的糖友要捏起皮肤45度进针，肚皮厚的胖友可以90度垂直进针，推完药之后要停10秒再拔针，不然药会跟着针头流出来。我之前拔完针经常看到针孔流透明的液体，就是药漏了，药量不够血糖肯定控不好。
另外针头必须一次性使用，我之前为了省钱一个针头用三四次，后来针头都变弯了都没发现，扎的时候特别疼，肚皮上还长了好几个硬疙瘩，打进去的胰岛素半天都不吸收，血糖忽高忽低，后来每天换一个新针头，硬疙瘩慢慢消了，血糖也稳了很多。
### 打完之后的注意事项
打完一定要立刻记下来打了多少单位、什么时间打的，避免漏打或者重复打。我之前有一次晚上追剧，忘了有没有打长效胰岛素，吓得半夜起来测了3次血糖，还好没打多，后来我每次打完就在手机备忘录记一下，再也没出过差错。另外身边一定要常备糖块，万一出现心慌、出冷汗、手抖的低血糖情况，立刻吃15克糖（大概半瓶含糖可乐、或者4块方糖），15分钟之后再测血糖。

## 我控糖3年的成功经验：胰岛素不是万能的，配合这2点效果更好
我现在糖化血红蛋白一直稳定在6.1左右，跟正常人差不多，除了规范打胰岛素，还有两个关键：
第一是严格配合饮食和运动：我现在每天的碳水是固定的，早上1个杂粮馒头，中午2两杂粮饭，晚上1两米饭，不吃精制糖，每顿饭后走30分钟，餐后血糖基本都能控制在8以下。
第二是定期监测血糖：我每周测2-3天的空腹+三餐后2小时血糖，每个月测一次睡前血糖，每3个月去医院查一次糖化血红蛋白，医生可以根据血糖情况调整胰岛素的用量，去年我测出来餐后血糖总是偏高，医生给我加了2单位的短效胰岛素，很快就稳了。

## 常见问题（FAQ）
### 1. 1型和2型糖友都需要打胰岛素吗？
不是的，1型糖友因为胰岛完全丧失了分泌功能，所以必须终身打胰岛素控糖；2型糖友只有初发高血糖需要强化治疗、口服药控糖效果差、出现并发症、或者怀孕的时候才需要打，很多2型糖友控糖好的话，后期还可以换回口服药。
### 2. 打胰岛素会不会发胖？
我刚开始打胰岛素的前3个月确实胖了4斤，当时特别焦虑，后来问了医生才知道，之前血糖太高，吃进去的糖都随尿液排出去了，身体吸收不到营养所以会瘦，打了胰岛素之后糖能被身体正常利用吸收了，要是管不住嘴就容易长胖。我后来调整了饮食，每顿减少20%的主食，每天饭后走30分钟，两个月就把涨上来的体重减回去了，现在一直保持在标准体重。
### 3. 胰岛素只能打肚皮吗？
不是的，吸收速度从快到慢是腹部>手臂外侧>大腿外侧>臀部，我有时候出门不方便露肚皮，就打手臂外侧，但是要注意每次换注射位置，两次注射至少间隔2厘米，不要总打同一个地方，不然容易长硬结，影响药物吸收。
### 4. 打了胰岛素之后还能改成口服药吗？
当然可以，我自己就是最好的例子，初发的时候打了半年胰岛素，胰岛功能恢复之后，就改成口服降糖药，控了1年多血糖都很稳，后来是因为工作经常熬夜，饮食不规律，口服药压不住才又打胰岛素的，只要胰岛功能还行，遵医嘱完全可以换成口服药。
