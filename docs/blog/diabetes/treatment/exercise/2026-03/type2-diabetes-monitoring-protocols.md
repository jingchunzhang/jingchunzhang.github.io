# 2型糖尿病监测协议：家庭可执行版本

> **[English Version](./type2-diabetes-monitoring-protocols-en)** | **[英文版入口](./type2-diabetes-monitoring-protocols-en)**

很多人每天都在测血糖，却仍然不知道下一步该怎么做。问题通常不在“测得不够多”，而在“没有协议”。2型糖尿病管理更像项目管理：要有固定采样点、统一记录格式、周期性复盘和明确的触发动作。本文给你一套家庭可执行的监测协议。

## 监测目标：从“数值焦虑”到“趋势决策”

建议把目标分成三层：

- **短期目标**：识别高波动时段
- **中期目标**：找到可持续的饮食/活动组合
- **长期目标**：把趋势数据用于门诊协同和并发症风险管理

## 家庭协议四步法

### 第一步：固定时点

起步建议：空腹 + 一餐后2小时 + 睡前。每周至少4天保持一致采样。

### 第二步：配套记录

每个读数都配一个“行为上下文”：

- 本餐结构（碳水/蛋白/蔬菜比例）
- 餐后是否步行
- 睡眠时长
- 当天压力强度

### 第三步：每周复盘

重点不是平均值，而是“重复问题”。例如：每逢晚餐精制主食偏多，2小时后明显上冲。

### 第四步：触发动作

针对重复问题设小动作：

- 晚餐主食减1/4并增加蔬菜
- 餐后固定步行15分钟
- 压力高的日子提前做低糖加餐计划

## 运动与监测如何配合

运动是2型糖尿病监测协议里最容易被忽略的一环。建议做“前后对照”：

- 同样餐食，分别在“步行”和“不步行”两天测餐后2小时
- 比较差异后，形成你的个体化活动阈值

这种方法比泛泛建议更能提高执行意愿。

## 7天执行清单

- [ ] 确定本周固定采样时点
- [ ] 使用统一表格记录血糖+行为上下文
- [ ] 至少完成2次“餐后步行对照日”
- [ ] 周末完成15分钟趋势复盘
- [ ] 写下1条下周要验证的改进行动

## FAQ

### Q1：是不是测得越多越好？
A：不是。关键在于可持续与可解释。没有复盘的高频测量，价值有限。

### Q2：偶尔一次高值要不要慌？
A：单点异常先看上下文（睡眠、压力、饮食）。若连续重复再和医生讨论调整。

### Q3：没有CGM还能做好监测吗？
A：可以。指尖血糖+结构化记录同样能形成高质量趋势数据。
