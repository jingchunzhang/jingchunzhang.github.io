# 1型糖尿病：把门诊建议落成家庭日程

> **[English Version](./type1-diabetes-clinic-to-home-plan-en)** | **[英文版入口](./type1-diabetes-clinic-to-home-plan-en)**

1型糖尿病管理复杂，最怕“知道很多但执行混乱”。把方案写成日程，能显著减轻压力。

## 每日执行骨架
- 早晨基础监测。
- 围绕三餐的监测与用药沟通。
- 运动前后风险管理。
- 夜间低血糖预防检查。

## 家庭安全清单
1. 低血糖急救物资固定位置存放。
2. 家属掌握紧急处理步骤。
3. 建立“今天变化点”简短日志，便于复诊沟通。
