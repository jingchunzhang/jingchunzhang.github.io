# 糖尿病前期预警信号：这个月先盯住哪些指标

> **[English Version](./prediabetes-early-warning-signs-en)** | **[英文版入口](./prediabetes-early-warning-signs-en)**

糖尿病前期往往“没感觉”，但数据通常会提前给出信号。

## 常见预警点
- 空腹血糖在多次检测中持续上移。
- 餐后血糖回落变慢。
- HbA1c 在复查中逐步升高。

## 30天行动重点
1. 建立“血糖-饮食-活动”简表。
2. 每次正餐后步行10–20分钟。
3. 用高纤维替代高糖零食。
4. 每周复盘趋势，不被单次波动带节奏。
