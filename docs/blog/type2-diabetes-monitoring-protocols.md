# 2型糖尿病监测协议：家庭可执行版本

> **[English Version](./type2-diabetes-monitoring-protocols-en)** | **[英文版入口](./type2-diabetes-monitoring-protocols-en)**

2型糖尿病监测的重点不是“多测”，而是“有结构地测”。

## 家庭协议四步
1. 固定监测窗口（空腹+餐后）。
2. 每个数据点配套记录饮食与活动。
3. 每周看模式，再做行为调整。
4. 就诊前准备一页趋势摘要。

## 复诊前建议携带
- 2–4周趋势记录。
- 重复高值/低值时段说明。
- 用药时点和不适反应问题清单。
