## 健康甜点制作

### 1. 黑巧克力坚果球

**食材：**
- 黑巧克力（70%）100克
- 坚果（杏仁、核桃）50克
- 椰子油 1勺

**做法：**
1. 巧克力隔水融化
2. 加入坚果碎和椰子油
3. 搅拌均匀
4. 冷却后切小块
5. 每次吃2-3块（约30克）

**保存：** 冷藏可保存2周

### 2. 希腊酸奶水果杯

**食材：**
- 希腊酸奶 150克
- 蓝莓 30克
- 草莓 30克
- 坚果 10克

**做法：**
1. 酸奶放入杯中
2. 摆上水果
3. 撒上坚果
4. 冷藏保存

**保存：** 当天吃完

### 3. 豆腐巧克力慕斯

**食材：**
- 嫩豆腐 200克
- 可可粉 2勺
- 甜菊糖 1勺
- 香草精 少许

**做法：**
1. 豆腐用料理机打碎
2. 加入可可粉、甜菊糖、香草精
3. 搅拌至顺滑
4. 冷藏2小时后食用
5. 每次100克

**保存：** 冷藏3天

### 4. 水果冰棒

**食材：**
- 酸奶 200克
- 蓝莓 50克
- 香蕉 1根
- 薄荷叶 少许

**做法：**
1. 所有食材放入搅拌机
2. 搅拌成奶昔
3. 倒入冰棒模具
4. 冷冻4小时以上

**保存：** 冷冻1个月

### 5. 坚果能量球

**食材：**
- 燕麦片 100克
- 花生酱 50克
- 枫糖浆 2勺
- 巧克力碎 30克
- 奇亚籽 1勺

**做法：**
1. 所有食材混合均匀
2. 搓成小球（每个约20克）
